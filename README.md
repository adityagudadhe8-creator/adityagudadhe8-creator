## 🚀 Featured Projects

### 1. GraphRAG with Neo4j, LangChain & Azure OpenAI

An end-to-end, notebook-based GraphRAG demonstration that processes PDF documents, extracts entities and relationships using an LLM, stores them in a Neo4j knowledge graph, and answers natural-language questions using retrieved graph context.

**Key features:**
- PDF loading and text chunking for document ingestion.
- LLM-based entity and relationship extraction.
- Knowledge graph creation and storage in Neo4j.
- Graph context retrieval and LLM-generated answers.
- Comparison of three entity retrieval strategies:
  - Direct entity matching
  - LLM-based entity extraction with partial matching
  - Neo4j full-text search with relevance scores
- Local Neo4j setup using Docker Compose.

**Tech stack:** Python, LangChain, Azure OpenAI, Neo4j, Cypher, Docker, PyPDF.
